Engineered for Flow

Everything you need from your shell without tmux splits, multiplexer gymnastics, or leaving your prompt.

Zero-Daemon Architecture

No persistent background server running in the background. Pressing your hotkey spawns a sub-millisecond ephemeral layer that owns the terminal buffer and releases it cleanly.

Real-Time Vitals

Direct kernel inspection of battery percentage, CPU load averages, physical RAM, disk capacity, and Git working tree state via native OS APIs (sysfs/procfs on Linux, sysctl on macOS).

Smart Workflow Discovery

Automatically inspects repository roots and synthesizes runnable commands for Cargo, npm/pnpm/yarn/bun, Python venvs/pytest/poetry, Go, Docker Compose, Make, CMake, and Just.

Bookmarks & Quick Jumps

Pin your most frequent directories with a single key (b). Jump directly to them or `cd` seamlessly straight back into your shell prompt.

Fuzzy Real-History Search

Pulls your live command history with deduplication and fuzzy sub-sequence matching. Auto-cleans timestamp clutters and pre-fills complex commands for editing.

Desktop & Clipboard Hooks

Press Tab on any file or folder to trigger actions: open in default application (`xdg-open` / `open`), launch file manager, or copy absolute paths into Wayland/X11/macOS clipboards.

Ergonomic Keyboard Shortcuts

Designed for pure keyboard navigation with familiar Vim keys and standard shell shortcuts.

Quick Installation

Get started in seconds on macOS or Linux.

Downloads the standalone binary, detects architecture (x86_64 or aarch64), and configures your shell hook automatically:

curl -fsSL https://raw.githubusercontent.com/IamShreshth/Tman/main/files/install.sh | bash
Then reload your active shell:
source ~/.zshrc                        # Zsh
source ~/.bashrc                       # Bash
tman init fish | source                # Fish

macOS (Apple Silicon M1/M2/M3/M4 & Intel) — One-line installer (auto-runs codesign and configures ~/.zshrc):

curl -fsSL https://raw.githubusercontent.com/IamShreshth/Tman/main/files/install.sh | bash
source ~/.zshrc

Homebrew + Cargo (Build from source on macOS):

brew install rust
cargo install --git https://github.com/IamShreshth/Tman.git --locked
echo 'eval "$(tman init zsh)"' >> ~/.zshrc && source ~/.zshrc

Arch Linux (Manjaro, EndeavourOS, CachyOS):

sudo pacman -S --needed --noconfirm base-devel git rust wl-clipboard xclip xdg-utils
curl -fsSL https://raw.githubusercontent.com/IamShreshth/Tman/main/files/install.sh | bash

Fedora (RHEL, CentOS Stream, Nobara):

sudo dnf install -y gcc git cargo rust wl-clipboard xclip xdg-utils
curl -fsSL https://raw.githubusercontent.com/IamShreshth/Tman/main/files/install.sh | bash

Ubuntu / Debian (Linux Mint, Pop!_OS):

sudo apt update && sudo apt install -y build-essential curl git cargo rustc wl-clipboard xclip xdg-utils
curl -fsSL https://raw.githubusercontent.com/IamShreshth/Tman/main/files/install.sh | bash

Compile and install via Cargo directly from the repository:

cargo install --git https://github.com/IamShreshth/Tman.git --locked
Append the hook to your shell configuration:
echo 'eval "$(tman init zsh)"' >> ~/.zshrc                        # Zsh
echo 'eval "$(tman init bash)"' >> ~/.bashrc                      # Bash
echo 'tman init fish | source' >> ~/.config/fish/config.fish      # Fish

Clone the repository and run the local builder:

git clone https://github.com/IamShreshth/Tman.git
cd Tman
./files/install.sh

Test the Linux build without modifying your local system:

# Run tests inside clean Linux container:
docker run --rm -v "$PWD":/usr/src/tman -w /usr/src/tman rust:slim cargo test

# Launch the interactive overlay in Linux:
docker run --rm -it -v "$PWD":/usr/src/tman -w /usr/src/tman rust:slim cargo run -- ui
