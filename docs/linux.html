Linux User Guide & Distro Setup

tman is engineered from the ground up in native Rust with zero external runtime dependencies. It compiles to a standalone, zero-daemon binary that works across standard GNU/Linux and musl distributions on both x86_64 and aarch64 (ARM64) architectures.

1. Distribution-Specific Installation

Select your Linux distribution below for exact package dependencies and activation steps:

1
Install toolchain prerequisites (if compiling via Cargo): 
sudo dnf install -y cargo rust
2
Run the single-step installer: 
curl -fsSL https://raw.githubusercontent.com/IamShreshth/Tman/main/files/install.sh | bash
3
Activate shell integration: 
source ~/.bashrc   # Or ~/.zshrc if using Zsh
1
Install Rust toolchain: 
sudo pacman -S --noconfirm rust
2
Run the installer: 
curl -fsSL https://raw.githubusercontent.com/IamShreshth/Tman/main/files/install.sh | bash
3
Activate in your shell: 
source ~/.bashrc   # Or source ~/.zshrc

2. Linux Keyboard Shortcuts & Terminal Emulators

💡 Why Ctrl+Space is the recommended Linux shortcut

Many Linux terminal emulators (GNOME Terminal, KDE Konsole, Tilix, and XFCE Terminal) have hardcoded application-level shortcuts where Ctrl+Shift+T opens a "New Tab" before key events can reach your shell prompt.

To solve this without forcing you to reconfigure your terminal emulator, tman init configures both Ctrl+Space (\C-@) and Ctrl+Shift+T by default on Linux.

Terminal Emulator Recommended Hotkey CSI u Protocol Support
Alacritty Ctrl+Space or Ctrl+Shift+T Supported via config
Kitty Ctrl+Space or Ctrl+Shift+T Native Kitty Keyboard Protocol
WezTerm Ctrl+Space or Ctrl+Shift+T Native CSI u Protocol
Foot (Wayland) Ctrl+Space or Ctrl+Shift+T Native CSI u Protocol
GNOME Terminal / Ptyxis Ctrl+Space Ctrl+Shift+T intercepted for New Tab
Konsole (KDE) Ctrl+Space Ctrl+Shift+T intercepted for New Tab

3. Kernel Telemetry & System Vitals

Unlike daemon-heavy monitoring tools, tman queries Linux virtual filesystems in user space with zero performance overhead:

Battery Telemetry

Queries /sys/class/power_supply/BAT* for capacity and status (with fallback to charge_now / charge_full or energy_now / energy_full). Gracefully hidden on desktop rigs and servers.

RAM / Memory

Parses MemTotal from /proc/meminfo with a standard libc::sysinfo fallback to accurately display total memory allocation.

CPU Load & Uptime

Uses libc::getloadavg with /proc/loadavg fallback for 1, 5, and 15-minute load averages, and /proc/uptime for machine uptime duration.

Filesystem Disk Space

Uses POSIX statvfs(2) with fragment size (f_frsize) and block size (f_bsize) fallbacks to reliably report free bytes and percentage used.

4. Wayland & X11 Clipboard Hooks

In tman's file actions menu (Tab), you can copy absolute file paths directly to your system clipboard. Install your desktop environment's clipboard utility: 

# For Wayland (GNOME, KDE Wayland, Sway, Hyprland):
sudo apt install wl-clipboard      # Ubuntu / Debian
sudo dnf install wl-clipboard      # Fedora
sudo pacman -S wl-clipboard        # Arch Linux

# For X11:
sudo apt install xclip             # Ubuntu / Debian
sudo dnf install xclip             # Fedora
sudo pacman -S xclip               # Arch Linux

Desktop File Manager & Opener:

Pressing Tab on any file presents "Open with app", and on directories presents "Open file manager". On Linux, this automatically delegates to xdg-open.

5. Testing in a Docker Sandbox

You can test tman inside an isolated Linux container on any machine with Docker installed:

# Run tests inside a Linux container:
docker run --rm -v "$PWD":/usr/src/tman -w /usr/src/tman rust:slim cargo test

# Launch the interactive overlay inside Linux:
docker run --rm -it -v "$PWD":/usr/src/tman -w /usr/src/tman rust:slim cargo run -- ui
